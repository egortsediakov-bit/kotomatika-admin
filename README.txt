КОТОМАТИКА Admin — PWA прототип

Что уже работает:
- мобильный и десктопный интерфейс;
- список заявок;
- поиск и фильтр по статусу;
- карточка заявки;
- смена статуса;
- назначение преподавателя;
- дата пробного урока;
- заметки менеджера;
- история заявки;
- раздел «Ученики»;
- базовая статистика;
- PWA manifest + service worker;
- установка на главный экран поддерживаемого телефона/браузера.

Сейчас используются ДЕМО-данные внутри app.js.
Реальная авторизация и YDB пока не подключены.

Рекомендуемая архитектура:
admin.kotomatika.ru
 -> Yandex Object Storage
 -> API Gateway
 -> Cloud Functions
 -> YDB

Локальный запуск:
python -m http.server 8080
открыть http://localhost:8080/

Важно: через file:// PWA и service worker нормально не работают.
