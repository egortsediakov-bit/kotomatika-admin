КОТОМАТИКА FRONTEND MASTER25 — точный график индивидуальных занятий

В поле «График» доступны ровно:
- Каждый день
- Каждые 2 дня
- Каждую неделю
- Каждые 2 недели
- Каждый месяц

«Количество занятий» всегда видно: от 1 до 52.
Если указать 1 — создаётся одно занятие.
По умолчанию выбран график «Каждую неделю», количество = 1.

После загрузки файлов в GitHub Pages сделайте Ctrl+F5.
