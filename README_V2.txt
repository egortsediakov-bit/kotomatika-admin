КОТОМАТИКА CRM PRO V2

Добавлено:
1. Глобальная кнопка «Обновить» в шапке — загружает свежие заявки из YDB без перезагрузки страницы.
2. Время последнего обновления.
3. «Удалить заявку» в карточке заявки.
   - удаляет запись из leads;
   - удаляет задачи заявки;
   - удаляет историю заявки;
   - если карточка ученика уже создана, она сохраняется и просто отвязывается от заявки.
4. «Удалить ученика» в карточке ученика.
   - удаляет карточку ученика;
   - удаляет его оплаты, занятия и задачи;
   - исходная заявка остаётся.
5. Перед каждым удалением показывается подтверждение.

Backend должен быть обновлён до KOTOMATIKA_CRM_PRO_API_V2_DELETE.zip.
