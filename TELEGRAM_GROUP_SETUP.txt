КОТОМАТИКА CRM — Telegram-группа

В текущем фронтенде уже есть поддержка Telegram на стороне CRM API:
- статус Telegram в разделе «Настройки»;
- кнопка «Отправить сводку»;
- backend ожидает переменные TELEGRAM_BOT_TOKEN и TELEGRAM_CHAT_ID.

ВАЖНО: токен бота нельзя помещать в app.js, index.html или публичный GitHub.
Он должен храниться только в переменных окружения Yandex Cloud Function.

Как подключить бота к группе:
1. Добавьте существующего Telegram-бота в нужную группу.
2. Напишите в группе любое сообщение после добавления бота.
3. Получите chat_id группы через Telegram Bot API getUpdates или через уже используемый вами способ получения chat_id.
   Для обычной группы/супергруппы ID обычно отрицательный (например -100...).
4. В Yandex Cloud -> Cloud Functions -> ваша CRM-функция -> переменные окружения добавьте:
   TELEGRAM_BOT_TOKEN=<токен от BotFather>
   TELEGRAM_CHAT_ID=<chat_id группы>
5. Создайте новую версию функции / примените изменения.
6. В CRM откройте «Настройки». Карточка Telegram должна показать «Подключён».
7. Нажмите «Отправить сводку» и проверьте сообщение в группе.

Для уведомлений о каждом событии (новая заявка, новый ученик, оплата и т.д.)
нужен код самой Yandex Cloud Function. В этом ZIP его нет: README_LIVE прямо указывает,
что backend обновлялся отдельным архивом KOTOMATIKA_ADMIN_API_FULL_DEMO_V4.zip.

Не публикуйте TELEGRAM_BOT_TOKEN в GitHub.
